# Maintenance template source registry

Business records store the stable references below. URLs live in this registry
so source locations can be audited or changed without rewriting tenant data.

## Company starter references

The `STARTER-*` records are Fleet Manager company-policy starting points. Their
intervals are deliberately conservative and always carry `SUGGESTED`
confidence. They are not manufacturer requirements. Blank intervals indicate
that a defensible generic value was not available.
